# project jimmy

# 📚 Novelku - Perpustakaan Novel Digital

Website perpustakaan digital sederhana untuk membaca dan menjelajahi koleksi novel klasik secara gratis.

🌐 **Demo Website:** [https://skykyojin.github.io/project-jimmy/](https://skykyojin.github.io/project-jimmy/)

---

## ✨ Fitur Website

- **Beranda & Koleksi Novel:** Menampilkan daftar novel terkenal lengkap dengan genre dan penulisnya.
- **Pustaka:** Halaman untuk melihat katalog novel.
- **Autentikasi & Profil:** Halaman Login dan Profil Pengguna.
- **Baca Online:** Akses langsung ke halaman baca masing-masing novel.

---

## 🛠️ Teknologi yang Digunakan

- **HTML5** - Untuk struktur halaman web.
- **CSS3** - Untuk penataan gaya dan tampilan.
- **GitHub Pages** - Untuk hosting/deployment website secara gratis.
